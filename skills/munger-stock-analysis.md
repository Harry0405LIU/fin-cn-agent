# 芒格式股票分析：逆向思考、多元思维模型与竞争格局

对 `$ARGUMENTS` 执行芒格式的单只股票分析，回答：

> 我会在这只股票上最可能怎样亏钱？这些失败路径是否已被价格充分反映？如果行业与竞争格局按当前趋势演变，10 年后这家公司的相对位置更强还是更弱？

本 workflow 为学习和研究用途，不构成个性化投资建议。芒格方法的第一原则是先排除愚蠢，再谈聪明："如果我知道我会死在哪里，我就永远不去那个地方。"

## 方法来源

本 skill 从项目中已有的芒格相关实践蒸馏而来：

- `reports/阿里巴巴/行业格局与竞争态势-芒格视角-20260513.md`：份额迁移、生态位、格栅思维

- `skills/industry-research.md`：行业与价值链研究方法

## Input

使用以下命令形式：

```text
/munger-stock-analysis "<company or ticker>" [mode=full|quick] [focus=industry|moat|failure|all]
```

公司或代码必填，其余字段可选，接受等价自然语言输入。不要臆造缺失值：标记为 `Unknown` 或 `Not calculable` 并说明后果。

- `mode=full`：产出完整报告（默认）
- `mode=quick`：只产出失败路径表 + 竞争格局速判
- `focus`：限定本次分析侧重（行业、护城河、失败路径或全部）

## Research Discipline

1. 研究前先运行 `date`，把数据截止日写入报告头部。
2. 优先使用年报、中期报告、业绩公告、监管文件、行业官方统计与交易所数据；二手来源只用于补缺并标注为二手。
3. 按 `skills/financial-data.md` 执行：涉及竞争份额、行业规模与关键财务数据时至少两个独立来源，差异 >1% 必须标记。
4. 每个时效性数据标注期间；每个实质陈述区分 **Verified fact**、**Estimate**、**Assumption**、**Analytical judgment**；概率估计必须说明依据。
5. 涉及计算（份额、增速、集中度、概率折算）必须调用 `python3 tools/financial_rigor.py`，禁止心算。
6. 报告保存后运行 `tools/report_audit.py extract` 与 `verdict`；未通过审计的报告只能算草稿。

## Execution Workflow

### 1. 解析输入与信息丰富度评级

确定证券、上市地、币种、mode 与 focus。信息丰富度评级：

| 等级 | 特征 | 对逆向检验的影响 |
|---|---|---|
| A级 | 资料充裕、共识强 | 共识越强越要做非共识检验：聪明人为什么不买/做空？ |
| B级 | 资料有限需推算 | 每个推算值标注置信度，失败路径概率给区间 |
| C级 | 信息稀缺 | 不假装完整，用第一性原理问"客户为什么付钱、替代品是什么" |

### 2. 反过来想：先找"死地"

列出这家公司所有合理的失败路径：

| 失败路径 | 概率 | 影响程度 | 触发信号 |
|---|---|---|---|
| | | | |

- 每个路径必须可证伪，不能只写"经营恶化"
- 历史类比：历史上处于相似位置的公司结局如何？
- **芒格式追问**：我最可能在哪里犯错？聪明人为什么不买/做空这家公司？

### 3. 行业规模与 10 年展望

- 行业规模、增速、所处阶段（成长期/存量期/衰退期）
- 增长来自大盘扩张还是抢份额？大盘低增长时，超额增速意味着零和博弈
- **芒格式追问**：这个行业 10 年后更好还是更差？

### 4. 竞争格局与生态位

- 主要对手逐一拆解：规模、增速、威胁等级
- 份额迁移历史与未来推演（如 4 年份额变化图）
- 生态位分析：公司占据哪个生态位？该生态位在扩张还是收缩？对手的生态位呢？
- 当消费者的入口发生不可逆迁移时，旧入口的价值必然被稀释——检查是否存在这种迁移

### 5. 护城河的芒格式检验

用芒格框架评估护城河：

| 来源 | 检验问题 | 宽度 | 趋势 |
|---|---|---|---|
| 转换成本 | 习惯、技能、文件格式、工作流锁定有多深？ | | |
| 品牌与定价权 | 提价后需求是否保持？ | | |
| 网络效应 | 是弱网络还是强网络？ | | |
| 规模经济 | 研发、成本、数据规模是否形成复利？ | | |
| 心理/习惯 | 用户心智是否已被固化？ | | |

**关键区分**：边缘侵蚀和核心替代是两件事。先判断今天的输赢发生在边缘还是核心，再判断"边缘会不会变成核心"。

### 6. 多元思维模型（格栅思维）

至少用 3 个不同学科的模型交叉检验，每个模型写明结论：

- 微观经济学：成本结构、边际成本、价格战可持续性
- 博弈论：入口层与履约层、份额战的纳什均衡
- 生态学：生态位分化、物种竞争
- 心理学：激励、社会认同、锚定
- 数学：复利、期望值、概率分布

模型结论冲突时必须显式记录，不要挑一个顺眼的。

### 7. 激励机制

- 谁的利益决定公司行为？管理层、渠道、客户、监管各自被什么激励？
- 激励机制是否让公司长期做正确的事，还是慢慢杀死公司？
- 管理层嘴上说与激励指向是否一致？

### 8. 空方论点与共识温差

- 写出你能找到的最强空方论点，逐条检验
- 市场共识是什么？你的判断与共识的温差在哪里？为什么你有信息优势？
- 非共识判断必须带证据、来源与置信度（如 60%），不能只是语感

### 9. 结论：下注纪律

恰好返回一个结论：

- `BET`（可下注：失败路径有限且价格已反映大部分风险）
- `INVESTIGATE`（值得深入研究）
- `WAIT`（等待更好价格或更清晰证据）
- `AVOID`（避开：失败路径太多或行业长期恶化）
- `INSUFFICIENT DATA`（数据不足）

结论需给出：最重要的死地、需要监控的触发信号、避免买入的条件、继续下注的条件、信心度。

## Blocking Gates

以下任一关卡失败即覆盖评分，不得用其他优点对冲：

- 行业长期变差且公司相对位置更弱
- 生态位收缩且没有可信的迁移路径
- 激励结构系统性作恶（如利益与股东长期冲突）
- 找不到任何可证伪的失败路径（说明研究不够，不是公司安全）
- 决策关键数据不足

## Required Report Format

以下标题恰好使用一次，不重复分析：

1. 执行摘要（非共识判断）
2. 结论与分类
3. 失败路径清单（死地）
4. 行业规模与 10 年展望
5. 竞争格局与生态位
6. 护城河检验
7. 多元思维模型交叉验证
8. 激励机制
9. 空方论点与共识温差
10. 芒格式追问
11. 下注条件与监控指标
12. 数据来源与质量

保存到 `reports/{company}-munger-stock-analysis-{YYYYMMDD}.md`（公司已有目录时放入该目录），使用文件系统安全标识符。数据来源一节须包含来源标题、发布方、发布日期、访问日期、报告期、URL 与一手/二手标注。
