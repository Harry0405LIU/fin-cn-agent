# 巴菲特式股票分析：生意质量、经济护城河、管理层与安全边际

对 `$ARGUMENTS` 执行巴菲特式的单只股票分析，回答：

> 这是一门我能看懂、10 年后还能持续赚钱、管理层值得信任、且当前价格留足安全边际的生意吗？

本 workflow 为学习和研究用途，不构成个性化投资建议。巴菲特方法的核心不是"好公司就买"，而是"好公司 + 好价格 + 好管理层 + 在能力圈内"。"好公司买贵了"同样是坏投资。

## 方法来源

本 skill 从项目中已有的巴菲特相关实践蒸馏而来：

- `reports/*/02-财务估值分析-巴菲特视角.md`：数据验算、五年经济表现、ROE/ROIC、现金流、资产负债表安全垫、三情景估值与反面检验
- `reports/巴菲特镜子测试-*.md` 与 `实盘记录/*_镜子测试_*.md`：生意本质、护城河、管理层、估值与安全边际、判断错误后果五维框架
- `skills/investment-checklist.md`：买入前六关筛选
- `skills/investment-research.md` 与 `skills/financial-data.md`：数据纪律与共享工具链

## Input

使用以下命令形式：

```text
/buffett-stock-analysis "<company or ticker>" [mode=full|quick] [benchmark=...] [horizon=...]
```

公司或代码必填，其余字段可选，接受等价自然语言输入。不要臆造缺失值：标记为 `Unknown` 或 `Not calculable` 并说明后果。

- `mode=full`：产出完整报告（默认）
- `mode=quick`：只产出镜子测试评分表 + 一页结论
- `benchmark`：指定估值对比基准（如同行、自身历史分位）
- `horizon`：持有期假设，默认 5-10 年

## Research Discipline

1. 研究前先运行 `date`，把数据截止日写入报告头部。
2. 优先使用年报、中期报告、业绩公告、监管文件和交易所数据；二手来源只用于补缺并标注为二手。
3. 按 `skills/financial-data.md` 执行：关键财务数据至少两个独立来源，差异 >1% 必须标记。
4. 每个时效性数据标注期间；每个实质陈述区分 **Verified fact**、**Estimate**、**Assumption**、**Analytical judgment**。
5. 所有决策敏感的计算必须调用 `python3 tools/financial_rigor.py`，禁止心算。
6. 报告保存后运行 `tools/report_audit.py extract` 与 `verdict`；未通过审计的报告只能算草稿。

## Execution Workflow

### 1. 解析输入与信息丰富度评级

确定证券、上市地、币种、mode、benchmark 与 horizon。先做信息丰富度评级：

| 等级 | 特征 | 对分析的影响 |
|---|---|---|
| A级 | 上市多年、数据充裕 | 警惕共识陷阱：指标再漂亮也要做反面检验 |
| B级 | 数据有限需推算 | 每个推算值标注置信度，不填充虚假确定性 |
| C级 | 信息稀缺 | 不勉强填满表格，诚实标注"数据不足"，聚焦第一性问题 |

### 2. 能力圈：一句话说清生意本质

- 这家公司靠什么赚钱？能不能用一句话说清？
- 10 年后大概率还在做什么生意？
- 决定成败的关键变量是哪几个？
- 认知来自深度研究还是道听途说？

**硬性否决**：如果连赚钱方式都说不清，直接标记 `PASS（不在能力圈，不分析）`，不继续。

### 3. 五年经济表现

表格展示最近 5 年（含最新季度/TTM）：

| 指标 | 年份1 | 年份2 | 年份3 | 年份4 | 年份5 | TTM |
|---|---|---|---|---|---|---|
| 营业收入与增速 | | | | | | |
| 归母净利润与增速 | | | | | | |
| 毛利率 | | | | | | |
| 经营利润率 | | | | | | |
| ROE | | | | | | |
| ROIC | | | | | | |
| 自由现金流 | | | | | | |

增速与 CAGR 必须用工具精确计算，禁止心算。正面与反面证据都要呈现：利润率改善是结构性的还是来自一次性项目？增长引擎正在切换吗？

### 4. 所有者盈余与现金流质量

- 经营现金流、资本开支、自由现金流（注明口径：是否含内容采购、经营租赁、收购）
- FCF 与净利润的现金转化率，连续多年对比
- 折旧政策、库存、应收账款、一次性损益、非经常项目
- "会计数字是估值的起点，不是终点。但起点错了，终点一定错。"

若官方口径与第三方口径差异 >1%，按公司披露口径统一并记录差异原因。

### 5. 经济护城河

逐一验证五类护城河：

| 护城河类型 | 验证方法 | 证据 | 变宽/变窄 |
|---|---|---|---|
| 品牌/定价权 | 能否不损销量提价？ | | |
| 转换成本 | 客户迁移成本多高？ | | |
| 网络效应 | 用户越多产品越好吗？ | | |
| 规模/成本优势 | 规模带来多大成本优势？ | | |
| 技术/专利壁垒 | 领先几年？能否复制？ | | |

追加检验：给竞争对手 100 亿，能不能复制这门生意？

**巴菲特式追问**：10 年后这条护城河还在吗？什么能摧毁它？

### 6. 管理层与资本配置

| 检查项 | 证据 | 评估 |
|---|---|---|
| 诚实度（承诺 vs 交付） | | |
| 资本配置（回购/分红/并购/再投资的回报率） | | |
| 股东利益一致性（持股、薪酬、减持记录） | | |
| 所有者心态（创始人 vs 职业经理人） | | |
| CEO 离开后能否照常运转 | | |

回购和分红要拆开看：回购是否在低价执行、分红是否挤压必要再投资、新业务投入的预期 ROIC 是多少。

### 7. 资产负债表与安全垫

- 现金、净现金/净债务、有息负债、债务到期结构、有息负债/净利润
- 非核心资产与投资组合：按保守折扣计入每股价值
- **安全垫是顺周期的**：股价下跌时它同步变薄，不能当成固定底

### 8. 内在价值与安全边际

先做估值概览（必须工具验算）：PE(TTM)、Forward PE、PB、股息率、FCF Yield、历史分位、同行对比。

再回答两个问题：

- 反向 DCF：当前股价隐含了什么增长预期？
- 三情景估值（必须工具精确计算，禁止心算）：

```bash
python3 tools/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {股本亿} \
  --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE} \
  --years 3 --currency {币种}
```

给出具体价格区间和安全边际。**巴菲特式追问**：如果股市明天关闭 5 年，你愿意以这个价格持有吗？如果判断错误，最多亏多少？

### 9. 巴菲特镜子测试评分

五维评分（每维 0-1 分，总分 /5，与项目镜子测试口径一致）：

| 维度 | 评分 | 核心证据 |
|---|---|---|
| 生意本质 | | |
| 护城河 | | |
| 管理层 | | |
| 估值 | | |
| 安全边际 | | |
| **总分** | **/5** | |

评分是判断辅助，不能覆盖硬性否决（见 Gates）。

### 10. 决策与输出

恰好返回一个结论：

- `BUY` / `ADD`（建仓/加仓）
- `HOLD – DO NOT ADD`（持有不加仓）
- `REDUCE` / `SELL`（减仓/卖出）
- `WATCHLIST`（观察）
- `PASS`（不在能力圈）
- `INSUFFICIENT DATA`（数据不足）

结论需给出：买入/加仓条件、价格区间、主要风险、卖出标准、跟踪指标、信心度。

## Blocking Gates

以下任一关卡失败即覆盖评分表，不得用高分对冲：

- 说不清赚钱方式（能力圈外）
- 无持久护城河且趋势在变窄
- 管理层存在诚信或治理硬伤
- 当前价格没有安全边际
- 决策关键数据不足

## Required Report Format

以下标题恰好使用一次，不重复分析：

1. 执行摘要
2. 结论与分类
3. 能力圈与生意本质
4. 五年经济表现
5. 所有者盈余与现金流质量
6. 经济护城河
7. 管理层与资本配置
8. 资产负债表安全垫
9. 内在价值与安全边际
10. 巴菲特镜子测试
11. 判断错误时的后果
12. 卖出与跟踪标准
13. 数据来源与质量

保存到 `reports/{company}-buffett-stock-analysis-{YYYYMMDD}.md`（公司已有目录时放入该目录），使用文件系统安全标识符。数据来源一节须包含来源标题、发布方、发布日期、访问日期、报告期、URL 与一手/二手标注。
